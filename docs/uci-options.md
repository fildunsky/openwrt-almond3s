# Настройки Almond через UCI: справочник `uci set almond3s.*`

Всё, что интерфейс умеет запоминать, лежит в секциях `almond3s.*` файла
`/etc/config/lcd`. Экран, скрипты и init читают их оттуда же, поэтому любую
настройку можно сменить из командной строки — без захода в меню устройства.

## Как применять

```sh
uci set almond3s.display.brightness='70'
uci commit almond3s
/etc/init.d/almond3s-lcd restart      # см. раздел «Когда нужен перезапуск»
```

`uci set` без `commit` только правит буфер в памяти — после перезагрузки или
`uci revert` изменение пропадёт.

Проверить, что получилось:

```sh
uci -q show almond3s                  # весь пакет
uci -q show almond3s.display          # одну секцию
uci -q get almond3s.display.lang
```

Сбросить секцию к значениям из пакета:

```sh
uci revert almond3s.display
```

## Когда нужен перезапуск

Часть настроек перечитывается при каждом обращении — такие подхватываются сразу
после `commit`. Остальные `ui.uc` читает один раз при старте и держит в
глобальных переменных, поэтому им нужен рестарт сервиса.

**Подхватываются сразу:** `brightness`, `warm`, `saver`, `saver_style`,
`night*`, `theme`, `pwmhz`, `pgamma`, `pcabc`, `pinv`, `pinit`, `clock_size`,
`dash_hold`, `led.*`, `alarm.*`, `zigbee.*`, `weather.*`.

**Требуют команды `/etc/init.d/almond3s-lcd restart`:** `lang`, `font`, `micons`,
`gradient`, `glow`, `bars`, `radius`, `touch_ms`, `dcust`.

Проще всегда делать рестарт — он занимает секунду и не вредит.

## Секция `display`

### Экран

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `brightness` | `5`…`100` | `100` | Яркость подсветки, % |
| `warm` | `0`, `30`, `60`, `100` | `0` | Тепло подсветки; `0` — не трогать |
| `theme` | `dark`, `light` | `dark` | Тема оформления |
| `bg` | `dark`, `light` | `light` | Оттенок фона внутри темы |
| `radius` | `0`…`4` | `0` | Скругление углов панелей |
| `gradient` | `0`, `1` | `1` | Градиентная заливка фона |
| `glow` | `0`, `1` | `1` | Мягкое свечение элементов |
| `bars` | `0`, `1` | `1` | Панели-полоски на главном экране |
| `font` | см. ниже | `combo` | Гарнитура |
| `lang` | `ru`, `en` | `ru` | Язык интерфейса |
| `rotate` | `0`, `1` | `0` | Поворот картинки на 180° |

```sh
uci set almond3s.display.brightness='30'
uci set almond3s.display.warm='60'
uci set almond3s.display.theme='light'
uci set almond3s.display.lang='en'
```

Значения `font`:

| Ключ | Описание |
|---|---|
| `std` | стандартный |
| `flipper` | узкий с «хвостиками» |
| `bitcell` | плотный пиксельный |
| `thin` | тонкий |
| `combo` | крупный `bitcell` + мелкий встроенный 5x7 |
| `lcd` | LCD-стиль |
| `hard` | жирный |
| `pixel` | крупный `hard` + мелкий `thin` |

```sh
uci set almond3s.display.font='hard'
```

### Энергосбережение и ночь

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `saver` | `30`, `60`, `120`, `300`, `600`, `1200`, `1800`, `0` | `300` | Затемнение после простоя, с; `0` — никогда |
| `saver_style` | `full`, `clock`, `line`, `dash`, `matrix`, `logo`, `off` | `dash` | Что показывает затемнение |
| `burnin` | `0`, `1` | `1` | Сдвиг против выгорания |
| `night` | `0`, `1` | `1` | Ночной режим вкл/выкл |
| `night_from` | `0`…`23` | `22` | Начало ночи, час |
| `night_to` | `0`…`23` | `6` | Конец ночи, час |
| `night_bright` | `3`, `5`, `7`, `10`, `15` | `15` | Яркость ночью, % |
| `night_warm_lvl` | `0`, `30`, `60`, `100` | `0` | Тепло ночью; `0` — не трогать |
| `night_wifi` | `0`, `1` | — | Выключать Wi-Fi ночью |
| `night_green` | `0`, `1` | `1` | Зелёный saver вместо обычного |
| `night_theme` | `0`, `1` | — | Тёмная тема ночью |

Интервал ночи умеет переходить через полночь (`22`→`6` — это «после 22 **или**
до 6»). Ночь — это окно яркости и optionally Wi-Fi, а не признак «на улице темно»:
для иконок погоды (солнце/серп) `ui.uc` считает закат сам по координатам города.

```sh
uci set almond3s.display.saver='0'                        # не гасить
uci set almond3s.display.saver_style='clock'              # часы вместо затемнения
uci set almond3s.display.night_from='21'
uci set almond3s.display.night_to='7'
uci set almond3s.display.night_wifi='1'                  # гасить Wi-Fi ночью
```

### Тач и заставка

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `touch_ms` | `20`…`200` | `60` | Длительность нажатия, мс |
| `clock_size` | `s`, `m`, `l` | `m` | Размер часов в заставке `clock` |
| `sv_date` | `0`, `1` | `1` | Показывать дату в заставке |
| `sv_signal` | `0`, `1` | `1` | Показывать уровень сигнала |
| `sv_batt` | `0`, `1` | `1` | Показывать батарею (если есть) |
| `sv_env` | `0`, `1` | `1` | Показывать температуру/влажность |
| `sv_wander` | `0`, `1` | `0` | Показывать время в других часовых поясах |

Флаговые `sv_*` работают только в заставках, которые их выводят: `sv_date`
пропускается в стиле `line`, `sv_wander` появляется только в `clock`,
`sv_batt` — лишь на моделях с батареей.

```sh
uci set almond3s.display.touch_ms='40'
uci set almond3s.display.saver_style='clock'
uci set almond3s.display.clock_size='l'
uci set almond3s.display.sv_wander='1'
```

### Панели LCD (для отладки)

| Параметр | Значения | Смысл |
|---|---|---|
| `pwmhz` | `50`…`20000`; в меню `120`, `250`, `500`, `1000`, `2000` | Частота ШИМ подсветки, по умолчанию `250` |
| `pgamma` | `1`…`4` | Гамма, по умолчанию `1` |
| `pcabc` | `0`…`3` | Полярность ABC-строк, по умолчанию `0` |
| `pinv` | `0`, `1` | Инверсия изображения, по умолчанию `0` |
| `pinit` | `kernel`, `boot` | Режим инициализации панели, по умолчанию `boot` |

Эти значения читает не `ui.uc`, а сам kmod; менять стоит только если картинка
ест или не ест контраст.

```sh
uci set almond3s.display.pwmhz='1000'
uci set almond3s.display.pinit='boot'
```

### Свои виджеты на главном экране

| Параметр | Значения | Смысл |
|---|---|---|
| `dcust` | строка | Раскладка виджетов по клеткам |
| `dash_hold` | `0`, `1` | Не возвращаться с других страниц на главную |

`dcust` — список через запятую, каждый элемент `клетка:страница:виджет[ШxВ]`:

```sh
uci set almond3s.display.dcust='0:lte:net,1:weather:wx_sun:2x1,2:clock:big:2x1'
```

* `клетка` — `0`…`63`, где `0`…`15` первая страница, `16`…`31` вторая и т. д.;
* `ШxВ` — размер в клетках, каждая `1`…`4`, необязательно (по умолчанию `1x1`);
* страница: `lte`, `weather`, `clock`, `net`, `wifi`, `zigbee`, `alarm`, …;
* виджет: `net`, `big`, `wx_<ключ погоды>`, `ic_<имя>`, `txt_*`, …

Список доступных ключей погодных иконок — `wx_sun`, `wx_moon`, `wx_partly`,
`wx_partly_night`, `wx_cloud`, `wx_rain`, `wx_snow`, `wx_fog`, `wx_storm`
(см. `WICONS` в `ui.uc`). Пустое значение означает «использовать умолчания»:

```sh
uci -q delete almond3s.display.dcust
```

## Секция `weather`

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `provider` | `openmeteo`, `wttr`, `metno`, `gismeteo` | `openmeteo` | Источник погоды |
| `city` | строка | `Moscow` | Название города для геокодирования |
| `lat` | `-90`…`90` | — | Закреплённая широта |
| `lon` | `-180`…`180` | — | Закреплённая долгота |
| `name` | строка | — | Локализованное имя для показа |
| `choices` | список | — | Пресеты в пикере городов |

```sh
uci set almond3s.weather.provider='metno'
uci set almond3s.weather.city='Vladivostok'
uci -q delete almond3s.weather.lat
uci -q delete almond3s.weather.lon
uci -q delete almond3s.weather.name
uci commit almond3s
/etc/almond3s/scripts/weather_fetch.sh && cat /tmp/lcd_weather.txt
```

### Про `lat`/`lon` — важно

`lat` и `lon` это «закреплённый выбор из пикера». `weather_fetch.sh` читает их
как `${WLAT-...}` — **одно** тире, без двоеточия. Это сделано намеренно: экран
зовёт скрипт для пресетов с явно пустыми `WLAT= WLON=`, и скрипт обязан
геокодировать город по имени, а не молча взять прошлые координаты.

Поэтому:

* хотите сменить город **по имени** — удалите `lat`, `lon` и `name`
  (`uci -q delete ...`), тогда сработает геокодирование;
* хотите задать точку вручную — напишите `lat` и `lon` вместе с `city`.

Город с кириллицей геокодируется корректно только при закреплённых
координатах: имя уходит в URL без percent-encoding, и запрос не проходит.
Родной путь — пресеты из `choices` (латиница) или закреплённые координаты.

`openmeteo` на части сетей недоступен (таймаут на `api.open-meteo.com`), при
этом `geocoding-api.open-meteo.com` отвечает. Если погода не приходит —
переключитесь на `metno` или `gismeteo`.

## Секция `alarm`

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `enabled` | `0`, `1` | `0` | Будильник вкл/выкл |
| `hour` | `0`…`23` | `7` | Час |
| `minute` | `0`…`59` | `0` | Минута |
| `mode` | `once`, `daily` | `once` | Один раз или каждый день |
| `repeat` | `0`, `1`, `2`, `5`, `10` | `0` | Повтор через N минут; `0` — нет |
| `sound` | `tone`, `ambulance`, `police`, `siren`, `mario` | `tone` | Мелодия |
| `sound_args` | строка | — | Ноты для `tone` |
| `sound_label` | строка | — | Название в интерфейсе |
| `volume` | `0`…`1` | `1` | Громкость |

```sh
uci set almond3s.alarm.enabled='1'
uci set almond3s.alarm.hour='7'
uci set almond3s.alarm.minute='30'
uci set almond3s.alarm.mode='daily'
uci set almond3s.alarm.sound='police'
uci commit almond3s
```

`sound_args` — последовательность `частота длительность` через пробел, `0` в
качестве длительности означает паузу. Например, сирена своими нотами:

```sh
uci set almond3s.alarm.sound='tone'
uci set almond3s.alarm.sound_args='660 240 784 720 0 400 784 240 660 720'
```

Менять `sound` и `sound_args` вместе: `ui.uc` не сверяет их и возьмёт мелодию
из `sound` с нотами из `sound_args`.

## Секция `mqtt`

Демон `almond3s-mqtt` публикует телеметрию в MQTT-брокер и (в зависимости от
`control`) принимает оттуда команды.

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `enabled` | `0`, `1` | `0` | Включить демон |
| `host` | адрес | пусто | Брокер; **без него демон не стартует** |
| `port` | `1`…`65535` | `1883` | Порт брокера |
| `user` | строка | пусто | Логин; пусто — без авторизации |
| `pass` | строка | пусто | Пароль |
| `node` | строка | имя хоста роутера | Имя узла в темах |
| `prefix` | строка | `almond3s` | Корневой префикс тем |
| `period` | секунды | `60` | Как часто публиковать |
| `control` | `off`, `ha`, `homed`, `both` | `off` | Какие темы управления слушать |
| `homed_prefix` | строка | `homed` | Префикс тем HOMEd |
| `retain` | `0`, `1` | `0` | Retain на теме состояния |

```sh
# секцию надо создать - иначе uci set вернёт "Invalid argument"
uci set almond3s.mqtt=mqtt
uci set almond3s.mqtt.enabled='1'
uci set almond3s.mqtt.host='192.168.1.10' #адрес брокера, тот же что у Homed
uci set almond3s.mqtt.user='user' #если брокер с авторизацией
uci set almond3s.mqtt.pass='password'
uci commit almond3s
/etc/init.d/almond3s-mqtt restart
```

Проверить:

```sh
uci -q show almond3s.mqtt
/etc/init.d/almond3s-mqtt running && echo "демон поднят"
ps w | grep '[a]lmond3s-mqtt'
```

### Демон молчит при неудаче

Если брокера нет или он не отвечает, демон **не пишет в лог ничего** — он
просто повторяет попытку каждые 15 секунд. Единственная запись появляется при
успешном подключении:

```sh
logread -e almond3s-mqtt | grep подключено
# подключено к 192.168.1.10:1883
```

Поэтому, если `running` есть, а этой строки нет, причина почти наверняка в
брокере: неверный адрес или порт, файрвол, неверный логин-пароль. Проверить
достижимость можно независимо от демона:

```sh
nc -zv 192.168.1.10 1883
```

### TLS нет

Клиент публикует **открытым текстом**, без TLS и без проверки сертификата — брокер, который требует
шифрование не подойдёт, надо ставить, например: **mosquitto-nossl** 


### Требование к `host`

`host` обязателен: без него `start_service` выходит сразу, и демон не
поднимается, даже если `enabled=1`. Если секции `mqtt` в `/etc/config/lcd` нет,
`uci set almond3s.mqtt.enabled=1` вернёт `Invalid argument` — создайте секцию
целиком через `uci set almond3s.mqtt=mqtt`.

### Автозапуск

`/etc/init.d/almond3s-mqtt enable` создаёт ссылку в `/etc/rc.d` для старта при
загрузке; без неё демон поднимается только вручную. Проверить состояние:

```sh
/etc/init.d/almond3s-mqtt enabled   # будет ли стартовать при загрузке
/etc/init.d/almond3s-mqtt running   # работает ли сейчас
```

Секция `mqtt` объявлена в init как `START=96`, то есть поднимается поздно —
после сети и модема, иначе демон не смог бы до них дотянуться.

### `control` — удалённое управление

| Значение | Что слушает |
|---|---|
| `off` | Только публикация метрик (по умолчанию) |
| `ha` | Топик Home Assistant: выключатели и кнопки |
| `homed` | Топики HOMEd `td`/`fd` службы custom |
| `both` | Оба набора сразу |Будьте осторожны со скриптами, не выдавайте брокеру доступ из интернета.

Доступны выключатели `vpn`, `screen`, `wifi_ap` и кнопки `modem_reset`,
`reboot`. Каждая команда запускает готовый скрипт из `/etc/almond3s/scripts`.
Будьте осторожны со скриптами, не выдавайте брокеру доступ из интернета.

### `retain`

Демон шлёт снимок состояния с флагом retain, чтобы подписчик увидел последние
значения сразу при подключении, не дожидаясь следующего цикла. Побочный эффект:
на брокере остаётся последний снимок и после выключения аппарата — для кого-то
это выглядит как свежие данные. Если это нежелательно, оставьте `retain=0`.

### Пароль в списке процессов

Демон запускается с данными для подключения к mqtt в аргументах, поэтому они видны в `ps` любому
пользователю роутера:

```sh
ps w | grep almond3s-mqtt
# /usr/libexec/almond3s/almond3s-mqtt 10.0.0.1 1883 node user pass almond3s 60 off homed 0
```

На домашнем запароленном роутере это обычно безопасно. Если не хотите светить данные придется использовать брокер во внутренней сети без пароля.

## Секция `led`

Только на моделях с диодом над экраном (Almond 3S, не Almond+).

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `state` | `0`, `1` | `1` | Диод вкл/выкл |
| `sms_blink` | `0`, `1` | `0` | Мигать при SMS |
| `color` | hex без `#` | `ffffff` | Цвет диода |

Допустимые цвета: `ffffff`, `ff0000`, `00ff00`, `0000ff`, `ffff00`, `00ffff`,
`ff00ff`, `ff4000`.

```sh
uci set almond3s.led.color='00ff00'
uci set almond3s.led.sms_blink='1'
```

## Секция `zigbee`

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `pan` | `1`…`65534` | случайный при первом запуске | Номер сети |
| `channel` | `11`…`26` | `15` | Канал |
| `mode` | `beacon`, `mesh` | `beacon` | Режим работы |
| `power` | `-8`…`20` | `8` | Мощность передатчика |
| `key` | hex | `3031…4445` | Ключ сети (network key) |
| `beacon` | `0`, `1` | `0` | Beacon-режим |

```sh
uci set almond3s.zigbee.channel='25'
uci set almond3s.zigbee.mode='mesh'
```

`pan` и `channel` перезаписываются «живыми» данными из `/tmp/lcd_zig_peers.json`
при каждом поднятии сети, так что ручная правка имеет смысла мало — меняйте
на экране или в zigbee2mqtt. ВНИМАНИЕ: смена `pan` выводит узлы из вашей сети,
после чего их придётся перевозить заново.

## Секция `services`

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `host` | список строк | `ya.ru`, `api.telegram.org`, `youtube.com`, `github.com` | Хосты для проверки связи |

```sh
uci add_list almond3s.services.host='ozon.ru'
uci add_list almond3s.services.host='max.ru'
uci del_list almond3s.services.host='youtube.com'
uci commit almond3s
```

Список — это просто цели для `ping`. Положительный результат на все хосты
означает «интернет есть», и только тогда включается индикатор.

## Секция `hw`

| Параметр | Значения | Смысл |
|---|---|---|
| `model` | `3s`, `plus`, … | Модель устройства |

Читает только `/etc/init.d/almond3s-lcd` при старте, чтобы выбрать панель и
набор виджетов. Правьте, только если устройство определилось неверно.

```sh
uci set almond3s.hw.model='3s'
```
