# ucheck-fwdref.py — детектор forward-ссылок для ui.uc

ucode НЕ хойстит: функция/переменная видит только объявленное ВЫШЕ по файлу.
Вызов функции, определённой ниже вызывающей, роняет демон в рантайме
(«access to undeclared variable»), procd входит в рестарт-цикл — на экране
это выглядит как «зависание» страницы.

КРИТИЧНО: эмулятор НЕ ловит это — хостовый ucode (свежий jow-/ucode) хойстит
топ-левел функции, а ucode на устройстве (OpenWrt) — нет. Forward-ref
проходит в эмуляторе и крашит на железе.

`ucode -T` проверяет только СИНТАКСИС, не forward-ref.

Запуск ПЕРЕД каждым деплоем ui.uc:
    python3 tools/ucheck-fwdref.py src/ui.uc

Чекер над-репортит (метит и легитимные глобал-вызовы), поэтому смотреть глазами
на новые срабатывания, относящиеся к правленым функциям.
